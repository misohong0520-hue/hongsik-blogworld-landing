# 사용 안내의 반복 로고와 재생 버튼 제거

이후 별도 사용자 요청으로 [안내 문구 3줄도 숨겼다](usage-notice-hidden.md). 아래 수치는 로고 행 제거 당시의 이력이다.

2026-10-30, 기준 `e148207`, 브랜치 `codex/landing-remove-repeated-logos`.

사용자 승인에 따라 PC·모바일 Figma의 사용 안내 아래 H 로고 4개와 사용하지 않는 재생 버튼 행을 제거했다. 새 요소는 추가하지 않았다. 사용 안내 문구·본문·문의 카드·헤더/푸터 브랜드 로고는 유지했다.

- PC 제거: `115:391`–`115:394`, 재생 그룹 `115:395`와 자식 `115:396`·`115:397`.
- 모바일 제거: 행 `123:482` 및 자식 `123:483`–`123:489`.
- 유지 문구: PC `115:387`, 모바일 `123:481`의 ‘사용 안내’. 본문 위 인용 장식은 변경하지 않았다.
- PC는 남은 요소와 문의 카드의 위치를 유지했다. 왼쪽 그룹의 경계 높이만 자동으로 588→482px로 줄었다. 루트 1440×5850은 유지됐다.
- 모바일은 66px 행과 32px 간격을 접어 문의 카드와 푸터를 98px 올렸다. 루트는 390×8890.668(출력 PNG 390×8891)이며, 문의 카드·푸터 내부 크기와 배치는 유지됐다.

## 검증과 인계

`design/usage-marks-removal.json`은 제거 ID, 변경 전후 크기·노드 수·지문을 기록한다. 삭제 노드와 위의 의도적인 경계/모바일 이동을 제외한 기존 노드의 부모·기하·채우기·텍스트·폰트 지문은 PC `22ff5330`, 모바일 `b4fc4166`으로 전후 일치했다. PC 608개, 모바일 536개 노드가 남았다. 메인 제품 이미지도 변경하지 않았다.

PC·모바일 전체 화면을 출력해 제거와 주변 배치를 시각 확인하고 `desktop-template.png`·`mobile-template.png`를 갱신했다. 새 제거 스크립트와 수정된 모바일 구성 스크립트의 문법, JSON 파싱, Git 공백 검사를 완료했다. 기존 원본 감사·메인 이미지 교체 감사의 수치와 노드 목록은 이전 상태의 기록으로 보존한다. `template-state.json`의 `usageMarksRemoval.removedNodeIds`는 과거 생성/매핑 기록에 남아 있더라도 현재 존재하지 않는 노드를 구분한다.

다시 모바일을 구성할 때도 반복 로고 행이 생기지 않도록 `figma-template-mobile.js`에서 해당 행 생성을 제거했다. 실제 웹 구현에서 원본 `0:392`–`0:398` 아바타/재생 그래픽과 모바일 행을 만들지 않는다. Figma 최종 프레임 ID는 PC `115:6`, 모바일 `123:5`로 같다.

이번 변경은 2단계 디자인 수정이다. 웹 런타임·의존성 변경이 없어 Next 빌드·타입 검사는 반복하지 않았다. 웹 구현·GitHub·AWS 배포, 기존 앱·WordPress는 변경하지 않았다.
