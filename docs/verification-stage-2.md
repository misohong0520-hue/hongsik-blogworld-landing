## 시각 검수

MCP PNG를 내려받아 원본 크기로 확인했다. 최종 파일은 `design/desktop.png`, `design/mobile.png`, `design/mobile-menu.png`다.

- 첫 검사에서 헤더·히어로의 자동 높이 설정으로 발생한 잘림을 찾아 수정했다.
- H 인스턴스 크기 조정 시 자식 이미지가 넘치는 문제를 스케일 제약과 비율 조정으로 수정했다.
- 펼친 FAQ는 마이너스, 접힌 FAQ는 플러스로 구분했다.
- 모바일 주요 문단의 어색한 단어 분할을 의미 단위 줄바꿈으로 정리했다.
- 메뉴 닫기 SVG의 부모·좌표 문제를 수정한 뒤 해당 화면을 다시 확인했다.
- 독립 검토자가 PC·모바일 스크린샷을 읽기 전용으로 검토했다. 큰 잘림·겹침과 미검증 홍보 주장 없음이 확인됐다. 발견한 문서 차이는 최종 카피에 맞췄다.

## 검증 범위와 다음 단계

- 웹 화면·앱 기능·설정·프롬프트·계정·DB·서버·WordPress를 수정하지 않았다.
- Figma 프로토타입 반응은 연결 및 속성 확인까지 수행했다. 실제 브라우저 메뉴·FAQ·메일 앱 동작, 키보드 접근성 검증은 4~5단계에서 진행한다.
- Next.js 실행 소스와 의존성 변경이 없어 1단계에서 통과한 빌드·타입 검사를 반복하지 않았다. 이번에는 디자인 구조·폰트·스크린샷·인계 파일을 검사했다.
- 공개 GitHub·AWS·DNS·HTTPS 변경은 하지 않았다. 배포 주소는 예정 주소다.
- 커뮤니티 원본의 참고 링크와 Figma 공식 무료 파일 라이선스 설명을 기록했다. 개별 파일 상세 페이지는 열리지 않아 별도 작성자·조건의 완전한 확인을 주장하지 않는다. 공개 전 출처 표기를 재확인한다.
