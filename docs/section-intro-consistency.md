# 섹션 제목 계층 정리 — 2026-10-30

## 목적

첨부된 운영자 소개 화면의 읽기 흐름을 나머지 랜딩 섹션에도 적용했다. 작은 주제 표시 → 짧은 검정 제목 → 초록 강조 문장 → 회색 설명 → 필요한 경우 한 줄 이점 순서를 공통으로 사용한다.

## 적용 범위

`SectionIntro`를 공통 컴포넌트로 만들고 다음 섹션에 적용했다.

- 기능 미리보기: 글감부터 콘텐츠 확장까지 / 내 작업에 맞게 골라 쓰세요.
- 운영자 고민: 기존 승인 문구를 같은 계층으로 정리
- 곡선 기능 탐색: 분석한 그 자리에서 / 콘텐츠 제작을 시작하세요.
- 플랫폼: 정성 들여 만든 콘텐츠 / 다른 채널에서도 활용하세요.
- 시작 안내: 앱·계정·AI를 준비하고 / 내 방식으로 시작하세요.
- 기본 과정: 자료에서 원고로 / 확인한 뒤 내 채널에 발행하세요.

기능 카드의 기존 단계·영상·앵커·곡선 동작은 유지하고, 카드 제목의 두 번째 줄만 강조색으로 통일했다. Hero·문의·푸터는 변경하지 않았다.
