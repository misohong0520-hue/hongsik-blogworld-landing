# 2단계 원본 템플릿 정렬 수정

후속 승인 변경: 사용 안내 아래 반복된 H 로고 4개와 재생 버튼 행은 제거했다. 안내 문구·문의 카드를 유지하며 모바일에서만 행과 간격 98px를 접었다. [하단 장식 제거 기록](usage-marks-removal.md)을 함께 따른다.

후속 승인 변경: 메인 인물·배경·주변 카드는 사용자 제공 제품 이미지로 교체했다. 해당 영역에는 [메인 이미지 교체 기록](hero-product-image.md)을 우선 적용한다. 아래 원본 사진 2장 유지 기록은 교체 전 상태이며, 현재는 하단 작업 공간 사진만 유지한다.

사용자 검토에서 이전 `f36d71f` 시안이 선택한 템플릿과 달라졌다는 지적을 받았다. 기존 결과의 ‘2단계 완료’ 판정을 철회하고 원본을 직접 복제하는 방식으로 수정한다.

## 보존 기준

- 원본: 파일 `h2yyAh96bomjU0WmO6NRiw`, 메인 프레임 `0:7` (1440×5850).
- 새 브랜드 페이지 `115:2`: `HongSik · Original layout`.
- PC는 `0:7.clone()`으로 만들었으며 수작업으로 레이아웃을 다시 그리지 않았다.
- 원본의 섹션 순서, 좌우 배치, 이미지·장식 위치, 3열 기능 카드와 3열 과정 카드, 회전, 크기, 간격, 둥근 모서리, 배경색·그라데이션·그림자, 이어지는 어두운 문의·푸터 영역을 유지한다.
- 원본 두 페이지와 프레임을 수정하지 않는다. 이전 브랜드 시안은 `Archive · Superseded layout` 페이지에 남긴다.

## 내용 교체 범위

- 이름·로고를 `HongSik BlogWorld`와 사용자 제공 초록 H로 바꾼다.
- 문구는 `design/template-copy.json`의 원본 TEXT ID별 130개 매핑을 따른다. 가격·실적·평점·고객 후기·제휴사 표현은 실제 앱의 준비·작성·검토·발행 안내로 바꾼다.
- 원본 사진 2장과 큰 일러스트는 이번 내부 Figma 시안에 유지한다. 장식용 템플릿 자산이며 실제 앱 화면이나 실제 이용자의 후기라고 설명하지 않는다. 공개 단계에서 사진·템플릿 출처와 이용 조건을 다시 확인한다.
- 고객사 표시 위치는 같은 자리에 H와 단계명으로 교체한다. 별점은 같은 슬롯의 체크로 바꾼다. 후기 아바타는 H로, 문의 영역의 금전 아이콘은 H로 교체한다.
- 브랜드 자리의 원본 160×30px 상자를 유지하고 그 안에 H 24px·앱 이름 13px를 넣는다. 긴 앱 이름을 넣기 위한 로고 내부 조정이며 주변 헤더·푸터 배치는 움직이지 않는다.
- 번역문 때문에 원본 상자가 늘어나지 않도록 텍스트의 위치·너비·높이·글자 크기·줄 간격을 고정한다. 한글은 Noto Sans KR로 바꾼다. 원본 Inter Semi Bold는 해당 한글 폰트에 같은 스타일명이 없어 Bold로 대응하며 나머지 Regular·Medium·Bold는 같은 굵기 계열을 따른다.
- 문의 버튼은 `mailto:support@hongsik.blog`에 연결한다. 화면의 입력란처럼 보이는 영역도 메일 앱으로 연결되는 안내임을 명시한다. 자동 발송 서버나 접수 완료를 흉내 내지 않는다.

## 구현 인계

원본의 실제 읽기 순서는 Header → Hero → 작업 흐름 라벨 → 연보라 설명 영역 → 3개 이미지 기능 카드 → 체크리스트·사진 → 3개 과정 카드 → 사용 안내·문의 → 어두운 Footer다.

모바일은 같은 내용·색상·그림·카드 개수·읽기 순서를 유지하며 세로로 재배치한다. PC를 통째로 축소한 이미지를 사용하지 않는다. 새로운 FAQ나 임의의 짙은 초록 패널을 추가하지 않는다.

실제 웹 구현은 3단계 이후다. 이 수정은 데스크톱 앱·설정·프롬프트·계정·WordPress·AWS에 영향을 주지 않는다.

최종 프레임 링크·검증 수치는 `docs/verification-template-correction.md`와 `design/template-state.json`에 기록한다.
