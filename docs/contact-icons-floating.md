# 작은 연락 채널·고정 상담 버튼 — 2026-10-30

사용자 제공 사각 메일 아이콘과 검정색 상담 버튼 이미지를 참고해 로컬 시안을 보완했다. 기준은 `1410587`, 작업 브랜치는 `codex/contact-icons-floating`이다. 공개 배포와 GitHub 전송은 승인 전까지 진행하지 않는다.

- 최신 요청으로 큰 문의 섹션 전체를 삭제했다. 왼쪽 큰 제목·설명·따옴표·‘사용 안내’·오른쪽 이메일 카드와 빈 여백을 모두 제거했다.
- 연락 방법은 푸터의 작은 사각 아이콘 7개(유튜브·커피컵·외부 링크·이메일·RSS·인스타그램·스레드)로 통합했다. 한 줄에 배치하며 좁은 화면에서는 너비에 맞춰 아이콘이 줄어든다. 채널명은 접근성 이름과 툴팁으로 제공한다.
- 사용자 답변으로 확인된 이메일은 `mailto:support@hongsik.blog`에 연결했다. 그 외 주소는 제공되지 않아 내부 설정값을 비워 두고 정적 아이콘으로만 표시한다. 연결 대기 문구·흐림·금지 커서·비활성 버튼 등 대기 표시는 하지 않는다. 채널 주소는 `src/lib/contact-channels.ts`에서 관리한다.
- 화면 오른쪽 아래에 둥근 ‘사용 상담’ 링크를 추가했다. 처음에는 참고 이미지의 검정색을 적용했으나, 이후 사용자 요청으로 사이트 공통 민트 배경(`#54bd95`)·짙은 글자(`#191a15`)·초록 말풍선(`#174d38`)으로 맞췄다. 호버는 다른 주요 버튼과 같은 `#43aa83`이다. 소스 기준 글자 대비 기본 7.58:1·호버 6.10:1, 아이콘 대비 기본 4.22:1·호버 3.39:1이다.
- 상담 링크는 푸터의 아이콘 모음 `#contact`로 이동한다. 실시간 채팅 서버나 외부 상담 주소를 새로 연결한 기능이 아니다. 기존 AnchorFocus의 이동·취소·포커스 처리를 재사용한다. 짧은 연락 영역도 문서 끝에서 ‘문의’ 메뉴가 선택되도록 보완했다.
- CSS `position: fixed`만 사용하며 스크롤 이벤트나 애니메이션 라이브러리를 추가하지 않았다. 모바일 터치 영역과 안전 영역 여백을 반영하고, 푸터 하단에 여유 공간을 두었다.

아이콘 브랜드 경로는 Simple Icons CC0 원본을 보관·표시한다. `/licenses/SimpleIcons-CC0.txt` 및 제3자 출처 문서를 함께 제공한다. 새 런타임 패키지는 설치하지 않았다.

동작 검사 28개 통과. 타입 검사·프로덕션 빌드·정적 자산/앵커/스타일 검사와 로컬 HTTP 응답도 확인한다. 실제 브라우저 렌더링 검수는 기존 브라우저 도구 연결 오류로 완료하지 못했다.
