## 3단계 인계

원본 `0:24` 콜라주 대신 새 제품 이미지 하나를 사용한다. Figma의 숨겨진 기존 인물 노드는 웹에 구현하지 않는다. 원본 정사각형 PNG를 단순 FIT하면 투명 여백이 커 보이므로, 위 콘텐츠 경계의 비율을 유지해 같은 슬롯 안에 표시한다. 별도 AI 호출·가상 데이터·기능 문구 추가는 없다.

실행 순서: `figma-hero-product.js`로 슬롯 생성 → `upload_assets`로 원본 PNG를 PC 이미지 레이어에 업로드 → `figma-hero-product-finish.js`로 모바일에 같은 채우기 적용 및 기존 그래픽 숨김 → `figma-hero-product-audit.js`로 검증. 스크립트는 Figma MCP 본문이며 Node.js 실행 파일이 아니다. ID는 `hero-product-state.json`의 현재 실제 값이다.

기존 템플릿 엄격 감사 자료는 교체 전 이력으로 보존한다. 최신 승인 예외와 검증은 `design/hero-product-state.json`, `design/hero-product-audit.json`에 있다. 원본 템플릿 페이지·데스크톱 앱·WordPress·AWS는 수정하지 않았다.
