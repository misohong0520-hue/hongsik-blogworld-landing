# 기능 중심 로컬 시안 — 2026-10-30

사용자가 참고 사이트의 내용 흐름과 앞서 분석한 곡선 인터랙션 구현을 승인했다. 이번 범위는 로컬 구현·확인까지이며, 공개 배포는 별도 승인 후 진행한다. 기준 소스는 `f288b9a`이며 브랜치는 `codex/feature-journey-local`이다. 앱 실행·프롬프트·계정·DB·AWS·WordPress는 수정하지 않았다.

## 내용과 화면

기존 자료 준비·작성·검토 설명을 여러 섹션에서 반복하던 구성을 핵심 기능 미리보기 → 운영자 고민 → 곡선으로 보는 기능 상세 → 지원 채널 → 실행 안내 → 짧은 기본 사용 과정으로 합쳤다. 승인된 메인 이미지, H 브랜드, 민트 색상, 이메일 문의 카드와 정리된 푸터는 유지했다.

곡선의 다섯 안내는 대시보드 / AI 글쓰기 / 카드뉴스·숏폼 / 발행·리포스트 / 자동 실행·색인이다. 필수 작업 단계가 아닌 기능 소개 순서이며, 기본 글쓰기 순서는 별도로 자료 준비 → AI 원고 작성 → 검토·발행으로 표시한다.

- 대시보드에서 글감·키워드 판단 후 글쓰기·숏폼 제작으로 이어지는 장점을 우선 소개한다.
- 일반 키워드 이동과 추천 글감의 이유·출처 전달을 전체 원문·분석 데이터의 무조건 재사용으로 확대하지 않는다.
- 블로그 발행 4개 채널과 인스타그램·스레드가 추가되는 리포스트를 구분한다. 동시 일괄 게시·모든 형식의 자동 재활용을 약속하지 않는다.
- 색인은 요청 및 기록 관리로 설명한다. 검색 노출·색인 완료·수익·생성 속도를 보장하는 수치를 넣지 않는다.
- 참고 사이트의 가격·판매 실적·후기·인물·이미지·소스 코드를 복사하지 않았다.

`public/images/dashboard-actual.png`는 사용자가 제공한 실제 HongSik BlogWorld 대시보드 캡처를 그대로 복사했다. 다른 기능 카드의 그래픽은 HTML/CSS·Lucide로 제작한 기능 흐름/형식 안내이며 실제 앱 실행 화면이라고 표기하지 않는다. 기존 승인된 노트북 메인 이미지는 유지했다.

## 인터랙션

`src/components/journey/feature-journey.tsx`는 서버 렌더링 본문과 장식 SVG를 담당한다. `journey-motion.tsx`는 카드 위치를 읽고 55% 화면 기준선과 카드 상단 간격으로 진행률을 보간한다. 구간별 pathLength=1을 사용해 노드와 선 끝이 일치한다. 현재 기능과 지난 기능이 누적 강조되고 역스크롤하면 되돌아간다.

- 기본 스크롤 유지, passive scroll + 이벤트당 RAF 합치기.
- ResizeObserver·폰트 준비·load·pageshow·resize에 위치 재확인.
- 색·테두리 중심 강조. 아직 도달하지 않은 본문도 읽을 수 있는 대비 유지.
- reduced-motion에서는 곡선·노드를 모두 강조한다. JS 없이도 모든 본문과 곡선 표시.
- 모바일은 고정된 작은 기능 탐색으로 바꾸고 해당 높이만큼 앵커 이동 간격을 보정한다.
- 기존 AnchorFocus의 0.4~0.9초 이동, 입력 시 취소, 완료 후 제목 포커스를 유지한다. 별칭 링크도 해당 카드 제목에 포커스를 준다.

## 로컬 실행

```text
npm run typecheck
npm run test:interactions
npm run build
node scripts/verify-export.mjs
node scripts/check-contrast.mjs
npm run preview
```

- 전체: http://127.0.0.1:3130/?review=feature-journey
- 곡선: http://127.0.0.1:3130/?review=feature-journey#features
- `preview`는 프로덕션 정적 결과 `out/`만 제공한다. 변경 후 build를 다시 실행한다.
- 127.0.0.1에만 바인딩한다. 다른 PC나 인터넷에 공개하지 않는다.
- CSS·JS·글꼴·이미지 MIME과 no-store를 제공하며 GET/HEAD만 허용한다. 중지는 Ctrl+C다.

- 소스 색상 대비 검사 통과. 브라우저 합성 결과 측정은 아니다.

- 공개 서버의 릴리스 전환·GitHub push·AWS 변경을 실행하지 않았다. 사용자가 로컬 시안을 확인하고 승인하면 그때 배포 절차를 진행한다.
