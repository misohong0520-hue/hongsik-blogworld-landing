# 과정 보기 아이콘 교체

2026-10-30, 기준 `2268b9d`, 브랜치 `codex/landing-process-arrow`.

사용자 승인에 따라 PC·모바일 ‘과정 보기’ 버튼의 재생 기호를 원형 아래쪽 화살표로 교체했다. 이 버튼은 이후 3단계 사용 과정 영역으로 이동하도록 4단계에서 연결하며 동영상 재생을 의미하지 않는다. 이번에는 실제 스크롤 동작을 구현하지 않았다.

| 화면 | 기존 아이콘 | 새 SVG 프레임 | 유지한 영역 |
| --- | --- | --- | --- |
| PC | `115:20` | `135:8` | 부모 `115:19`, x0 y0, 40×40 |
| 모바일 | `123:22` | `135:12` | 부모 `123:21`, x0 y0, 40×40 |

기존 인스턴스는 opacity 0으로 남겨 오토레이아웃 공간을 보존하고, 같은 자리에 네이티브 SVG 벡터를 절대 배치했다. 텍스트·간격·주변 버튼·전체 화면 크기는 유지했다. 원본 템플릿 페이지는 수정하지 않았다.

SVG는 설치된 lucide-react 1.64.0의 circle-arrow-down 도형 경로를 사용한다. 공개 자산은 `public/images/process-arrow-down.svg`, 라이선스 전문은 같은 폴더의 `process-arrow-down.LICENSE.txt`다. 임의의 회전 도형으로 화살표를 재구성하지 않았다.

`design/process-arrow-state.json`에 생성/변경 ID와 검증을 기록했다. 기존 아이콘 루트의 불투명도 변경 및 새 SVG 노드를 제외한 기존 노드의 기하·표시·채우기·텍스트·폰트 지문은 PC `2a243572`, 모바일 `6d78e8d2`로 전후 일치했다. 전체 화면을 출력해 화살표와 배치를 확인했다. PNG는 PC 1440×5850, 모바일 390×8781이다. 기존 모바일 구성 스크립트는 아이콘이 포함된 PC 버튼 그룹 `0:20`을 복제하므로 이후 생성에도 새 화살표가 함께 복제된다.

웹 런타임·의존성·로컬 앱 코드는 변경하지 않았다. 로컬 앱과 웹 연결에 대한 질문은 구조 검토와 설명만 했으며 실제 연결 기능은 구현하지 않았다.
