# 5단계 검수·수정 결과

기준 커밋 `64ec9f9`, 작업 브랜치 `codex/landing-stage-5`.

현재 상태는 **정적 검수와 발견한 문제 수정 완료, 실화면·Lighthouse 검수 미완료**다. 5단계 전체 완료로 처리하지 않는다.

## 1. 사용자 화면에서 발견한 배치 오류

사용자가 제공한 로컬 페이지 화면은 제목 크기·좌우 배치·카드 스타일이 적용되지 않고 내용이 세로로 나열된 상태였다.

원인은 `next.config.ts`의 Tailwind 로더 규칙이었다. `*.css` 전체를 `as: "*.css"`로 처리해 CSS Module 파일도 일반 CSS로 변환했다. 실제 HTML에 `class="landing-container undefined"` 같은 값이 있었고 header·section의 클래스가 누락됐다. CSS 파일 자체는 HTTP 200으로 제공되고 있었다.

로더 적용 범위를 **`globals.css`로 제한**했다. 수정 후 header의 실제 스코프 클래스와 대응 CSS가 생성되고, 9개 화면 영역의 클래스·CSS 연결이 검사에 통과했다. `undefined` 클래스 토큰은 0개다.

3·4단계의 타입 검사·빌드는 이 오류를 탐지하지 못했다. DOM 인터랙션 테스트는 CSS 모듈 이름을 대체하므로 실제 빌드의 CSS 매핑까지 확인하지 않는다. 이를 보완하기 위해 `scripts/verify-export.mjs`에 빌드 HTML과 CSS의 연결 검사를 추가했다. 파일 존재 검사만으로 화면 정상 동작을 판단하지 않는다.

## 2. 사용자 승인 글자색 대비 보완

배치·크기·민트 배경 `#54bd95`는 유지했다. 밝은 배경의 회색 본문을 `#626d67`, 민트 위 흰 글씨를 기존 진한 본문색 `#191a15`, 흰 배경의 초록 텍스트 링크를 `#237b57`로 보완했다. 어두운 문의·푸터의 회색 `#a6a6a6`은 유지한다.

| 조합 | 이전 | 수정 후 |
| --- | --- | --- |
| 본문 회색 / 흰 배경 | 2.43:1 | 5.38:1 |
| 글씨 / 민트 배경 | 2.31:1 | 7.58:1 |
| 본문 회색 / 연보라 배경 | 미달 | 5.10:1 |
| 본문 회색 / 옅은 민트 샘플 | 미달 | 4.70:1 |
| 초록 텍스트 링크 / 흰 배경 | 2.31:1 | 5.20:1 |

계산은 [W3C의 최소 명도 대비 설명](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)을 기준으로 한다. `scripts/check-contrast.mjs`가 주요 색상 조합 10개를 검사한다. 이는 소스 팔레트 검사이며 실제 브라우저 픽셀·그라데이션 합성·모든 상태의 접근성 준수를 보증하지 않는다. 로고·제품 이미지의 픽셀은 수정하지 않았다.

## 3. 검색·공유 정보

- canonical: `https://blogworld.hongsik.blog/`.
- Open Graph: 사이트명·제목·설명·한국어 로케일·website 유형·제품 이미지·이미지 대체 텍스트.
- Twitter: 정사각형 제품 이미지를 사용하는 summary 카드.
- 공유 이미지는 승인된 `public/images/hero-product.png`를 그대로 재사용한다. PNG 헤더와 실제 1600×1600 크기를 메타정보와 비교했다.
- `robots.txt`·`sitemap.xml`을 정적으로 내보낸다. 공개 배포 시 사용할 도메인을 참조하며, 외부 공개나 검색 등록은 하지 않았다.

이전 에셋 검사 44개는 주로 루트 기준 경로만 확인한 수치다. 이제 CSS의 상대 폰트 경로도 확인하므로 173개이며, 실제 첫 방문 다운로드 수나 성능 점수는 아니다.

사용자 확인은 CSS 연결 수정 후 기본 배치가 복구됐다는 근거다. 확인 당시의 뷰포트 크기는 제공되지 않았으며, Figma 정밀 비교·다른 화면 폭·키보드·Lighthouse 검증까지 완료했다는 뜻은 아니다.

## 5. 아직 수행하지 못한 검증

브라우저 도구가 계속 `Local browser use is disabled in Work settings`를 반환했다. 로컬 미리보기 열기는 요청했고 HTTP 정상 응답을 확인했지만, 도구로 화면이나 콘솔을 읽은 것은 아니다. 권한 제한을 다른 브라우저 자동화로 우회하지 않았다.

다음 항목은 미검증이다.

- 1440px·390px Figma와 실제 페이지의 글꼴·줄바꿈·위치·높이 비교.
- 320px·768px·1250px의 잘림·겹침·가로 스크롤.
- 실제 Tab·Enter·다음 Tab, 직접 해시·동일 링크·뒤로/앞으로, 새 탭·메일 앱.
- 모션 줄이기, 실제 합성 배경의 색 대비, 확대·화면 읽기 도구.
- 브라우저 콘솔·네트워크 오류, Lighthouse 성능·접근성·SEO 점수와 LCP·CLS.
- 공개 주소의 공유 미리보기·검색 수집·HTTPS·캐시·압축.

브라우저 검증이 끝나기 전 5단계 전체 완료나 Lighthouse 통과로 보고하지 않는다. 6단계 GitHub·AWS·DNS·HTTPS 배포도 진행하지 않았다. 기존 데스크톱 앱·프롬프트·계정·DB·WordPress는 수정하지 않았다.
