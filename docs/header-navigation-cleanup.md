# 상단 메뉴 중복 정리 — 2026-10-30

사용자가 지적한 상단의 반복 안내·문의 기능을 하나로 합쳤다. 기준은 `3c0df60`, 브랜치는 `codex/header-navigation-cleanup`이다. 이번 작업은 로컬 반영까지이며 공개 배포·GitHub 전송은 수행하지 않는다.

- Header의 별도 actions 묶음을 제거했다. 단일 HeaderNavigation이 홈 / 기능 / 이용 안내 / 사용 과정 / 문의를 표시한다.
- 문의 링크 하나만 사이트 공통 민트 CTA로 강조한다. 나머지는 균일한 여백과 연한 현재 위치 배경을 사용한다.
- 기존 고정 너비·130px 빈 간격을 제거하고, 글자 크기·굵기는 선택 전후 동일하게 유지한다.
- 메뉴는 얇은 테두리와 밝은 둥근 배경으로 묶었다. 새로운 블러·스크롤 핸들러·의존성은 추가하지 않았다.
- 좁은 화면에서는 브랜드 아래 행 전체에 메뉴를 표시한다. 기존 모바일 숨김 규칙을 제거했으며 링크 높이는 44px 이상이다.
- 기존 섹션 ID, AnchorFocus 이동·중단·포커스, 문서 끝에서 문의를 선택하는 로직을 유지한다.

타입 검사·기존 DOM 동작 검사 28개 통과. 프로덕션 정적 빌드와 앵커·스타일 연결 검사, 로컬 HTTP의 상단 링크 중복 여부를 확인한다. 실제 브라우저 PC·모바일 렌더링 검수는 기존 도구 연결 오류로 미완료다.
