# 이메일 문의 카드 안내 수정

기존 ‘방식: 메일 앱으로 연결’, ‘안내: 메일에서 작성해요’는 입력창이나 버튼이 아닌 정적 문구였다. 흰 입력창 형태 때문에 사용자가 비활성화된 입력란으로 오인해 클릭했다.

두 가짜 입력란을 제거하고 받는 주소, 메일 앱을 여는 방법, 실제 ‘메일 앱 열기’ 링크 하나로 정리했다. 메일 앱이 열리지 않으면 주소를 복사해 사용할 수 있도록 안내한다. 문의 주소는 `support@hongsik.blog`이며 다른 CTA와 기존 `mailto:` 연결은 유지한다.

메일 작성창 실행은 방문자 환경의 기본 메일 앱 설정에 따른다. 이 변경은 메일을 자동 발송하거나 이메일 전달 설정을 변경하지 않는다. 메일 수신 성공 여부는 별도 검증 대상이다.

검증: 타입 검사, 기존 DOM 상호작용 테스트 9개, 정적 빌드·에셋·스타일·링크·대비 검사를 통과했다. 브라우저 도구는 `Local browser use is disabled in Work settings`로 실제 화면 검수를 실행하지 못했다. 실제 메일 앱 실행과 송수신을 이 검사로 통과했다고 판단하지 않는다.
